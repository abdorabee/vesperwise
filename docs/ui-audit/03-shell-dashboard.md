# 03 — App shell + Dashboard home audit

Scope: `app/(dashboard)/layout.tsx`, `loading.tsx`, `dashboard/page.tsx`, `components/dashboard/*`, `components/dashboard/home/dashboard-home.tsx`, `components/app-ui/page-primitives.tsx`, `components/ui/sidebar`, `workspace-setup-error.tsx`, mascot. I audited the source and the rendered `/dev/shell` HTML. I had no screenshots, so every visual call below comes from reading the code. Skills applied: better-ui, emil-design-eng, ui-ux-pro-max, dataviz, interaction-design.

---

## 1. Verdict: **5 / 10** for "feels like a real SaaS"

The chrome is solid: shadcn `dashboard-01` sidebar, icon-collapse, ⌘K palette, and a credits meter. The KPI + chart + activity + movers + heatmap layout looks like Linear or Attio at a glance. The problem is that the home screen fakes a lot of its data, and anyone who looks closely will see it. Every sparkline is a hard-coded array that trends upward. The "Score distribution" area chart is a fixed SVG path, and it draws the same curve for every account that has ≥1 score. The 24H/7D/30D/90D range tabs, the All/Mine tabs and the `⋯` menus do nothing. Two nav items and two home cards say "Coming soon". An investor who clicks "30D" and sees nothing change, or who notices the curve rising while "HOT accounts: 1", will stop trusting every number on the page. Fix honesty first and polish second.

## 2. What's already good (keep)

- **Shell architecture.** shadcn `Sidebar` with `collapsible="icon"`, a rail, tooltips in collapsed mode, a `SidebarInset` and a breadcrumb header. This is the right skeleton and matches Linear/Vercel conventions (`components/dashboard/app-sidebar.tsx:181`, `dashboard-shell.tsx:64`).
- **Live nav badges.** The HOT count on Intent Hub (tinted hot), the unread count on Inbox and the watchlist count are all real server counts (`layout.tsx:33-52`, `app-sidebar.tsx:54-66`). They make the product feel alive.
- **Command palette.** ⌘K toggles it and Esc closes it. It has arrow-key navigation, 180 ms debounced remote search across companies, watchlist, people and lists, and a "Score {query}" action row (`search-palette.tsx:63-72`). It opens with no animation, which is correct for a high-frequency surface (Emil: "never animate keyboard-initiated actions").
- **Credits in the user menu.** A `1,234 / 5,000` meter with a progress bar and a "Top up" link, plus an sr-only credits label on the trigger (`nav-user.tsx:43-69, 101`).
- **Page primitives.** `PageHeader`, `MetricCard`, `PageSurface`, `EmptyState` and `InlineError` are clean, tokenized and use `tabular-nums` and `text-pretty` (`page-primitives.tsx`). They are just not used on the home page (see D9).
- **Real data plumbing.** Band counts use the latest score per domain, the activity feed merges score and autopilot events, and movers are ranked by |Δ| (`dashboard/page.tsx:64-143`).
- **Workspace-setup error screen.** It is on-brand and explains what happened and what to do next (`workspace-setup-error.tsx`).
- **Reduced motion.** It is respected on the sidebar chevron, header and credit bar (`motion-reduce:transition-none`).

## 4. Top 3 highest-leverage changes

1. **Make every number real or remove it (D1, D2, D3, D10).** Remove the fake sparklines and SVG curve, wire the range tabs to a `?range=` param, and delete the dead `⋯`/All-Mine controls. This takes about a day and removes the biggest risk: an investor catching fabricated charts.
2. **Rebuild the home around "who to call today" + a first-run state (D5, D6, D4).** The hero is a Hot-accounts list with logo, score, signal chips, AI reason and a CTA. Add a domain-input "Score a company" box on top. Remove all Autopilot "Coming soon" content from home. Seed the demo account with 30+ scored companies so the investor sees a populated product.
3. **Consolidate the shell (D8, D13, D14, D4).** Seven flat nav items, Search ⌘K at the top, the real logo glyph, a Plan badge, an always-visible credits meter in the sidebar footer, and no "Soon" items in primary nav. This takes a few hours and changes the first impression from a prototype to a product.

## 6. Design references that fit

- **Attio home / lists.** Company rows with favicon, attribute chips and dense tables; the best model for the Hot-accounts card.
- **Linear.** 44–48px header, flat neutral surfaces, accent used only for state, a ⌘K palette with Recent + Actions, and a nav of 6–7 items.
- **Common Room / Koala / Warmly.** The same category (buyer-intent signals). Their home is a "signals feed + who to reach out to" list, not a BI chart wall.
- **Vercel dashboard.** Honest empty states with one primary action, and a usage/credits meter in the sidebar.
- **shadcn `dashboard-01` block.** Already the base here; finish migrating the home body onto its `SectionCards` + `ChartAreaInteractive` (Recharts, real data, range `ToggleGroup`) + `DataTable` pattern.
