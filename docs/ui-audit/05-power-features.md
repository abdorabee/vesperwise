# 05 — Power features audit (Bulk, Lists, Pipeline/Intent Hub, People, Inbox, Autopilot)

Audited from source at commit `58c449d` (read-only; no browser). Skills applied: better-ui, emil-design-eng, interaction-design, ui-ux-pro-max, dataviz. Anything that depends on runtime rendering (actual pixel spacing, contrast of dark tokens) is marked *Not verified*.

## 1. Verdict — 4/10

The section has **two finished surfaces (Bulk, Lists)** and **four that look like a Linear/Superhuman mock with the wiring missing**. Pipeline ("Intent Hub", which is **#2 in the primary nav**) and People are full of dead controls and fake filters: roughly 20 elements that look clickable and do nothing. Autopilot is a "Coming soon" page with about 1,600 lines of finished-looking but unmounted UI behind it. Inbox is well built, but only one of its six event types is ever emitted, so in a demo it will almost certainly be empty or show one kind of card.

The worst single issue: **a Pipeline card's score pill is colored by the kanban column, not the score**. A company scored 88 that nobody has dragged yet sits in "Cold" with a grey pill. That contradicts the product's core promise (HOT ≥75) on the most prominent screen.

For the demo, cut this section down to **Bulk + Lists (+ Pipeline board only if fixed)** and hide the rest.

## 4. Top 3 highest-leverage changes

1. **Cut the nav to what works (30 min).** Remove Autopilot and API Keys "Coming soon" from the sidebar, hide People and Inbox for the demo, and drop "Run autopilot" from Lists. Four fewer half-built destinations reads as focus instead of sprawl. (P4, P5, P10)
2. **Make Pipeline honest (1–2 h).** Color pills by `score_band`, seed stages from band, and delete the dead Group/Sort/Options/filter chips, List/Timeline tabs, IQ ids and column "+". Add a standard page header named "Pipeline". The kanban then becomes a strong, true visual of "who's hot right now". (P1, P2, P3, P19, P21)
3. **Turn Bulk → List into one demo story (2–3 h).** Upload a 6-row CSV and watch the ranked results. Click "Save HOT to list", land on a smart list with rules chips and band mix, then Export. This joins the two finished surfaces into a workflow instead of two isolated tools. (P17, P18, P15, P22)

## 5. Design references

- **Linear**: board and list parity, where every toolbar control works. Also a model for a lean filter bar: one "Filter" button that builds chips, not decorative chips.
- **Attio / Folk**: lists as saved views over one account table (merge Watchlist, Lists and Pipeline into one record set with Table and Board views).
- **Clay**: the bulk enrichment table, with row-by-row streaming results and a determinate progress count.
- **Apollo / Common Room**: the signal-alert feed as a single column on the dashboard, not a separate email-client inbox, when event volume is low.
- **Superhuman / Height inbox**: only if events become high-volume; until then the three-pane inbox is over-built for the data.
