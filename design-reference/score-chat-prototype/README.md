# Score chat prototype

Design-first clickable HTML for the generative Score thread.

Locked: inline artifacts, new lime companion (same avatar engine later), state-only motion.

## Open

Open `index.html` in a browser. Use the top-right state chips, or:

- Empty → click **stripe.com** (goes Thinking, then Artifact)
- Artifact → click **Hiring** or **Show hiring evidence**
